# Interactive Habit Tracker

### Create a multi-page website that allows users to track habits throughout the week.

**Key Features:**
* A homepage that welcomes the user
* An about page to provide more context for the tool
* The habit tracking page that contains different habits that could be tracked
  * Each habit should be able to track if the goal was reached each day
